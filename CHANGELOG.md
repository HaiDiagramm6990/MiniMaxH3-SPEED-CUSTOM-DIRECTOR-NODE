# Changelog

## v1.1.0

- Added reference autocomplete and inline validation across the pass prompt editors. Assign project or shared library media from the dropdown and preview assigned references.
- Added Dialogue and Shot builders with cursor insertion, project-wide speaker IDs, Fantastic audio retention, and timing on H3’s native 24 fps grid.
- Added project-wide edit history with Ctrl+Z and Ctrl+Y. Reordering media updates citations to keep them attached to their original assets.
- Added render ETA, optional automatic memory cleanup, and direct image drops onto the I2VA and FL2VA first-frame card.
- Added project-only and shared reference library scopes for images, video, and audio.

## v1.0.0 — 2026-11-25

- First public release of the native MiniMax H3 SPEED Director for ComfyUI.
- Interactive scene timeline, independent pass durations and prompts, transition controls and project import/export.
- Fantastic T2VA, I2VA, FL2VA, L2VA and REF integration with mode-specific inputs and first-frame previews.
- Incremental render checkpoints, targeted regeneration, cancellation, resume and persistent project storage.
- CPU tiny-VAE live previews with configurable image and playback settings and native step telemetry.
- Synchronized film assembly, optional RIFE/RTX delivery and approval export through Save Video.
- Public installation guide, portable example workflow, troubleshooting and hardware benchmark notes.
